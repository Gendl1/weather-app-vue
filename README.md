# Weather Now

Веб-приложение прогноза погоды: поиск города, текущие условия, прогноз на неделю и почасовой прогноз.

**Демо:** [https://gendl1.github.io/weather-app-vue/]  
**Репозиторий:** [https://github.com/Gendl1/weather-app-vue]

## Стек

- Vue 3 (Composition API)
- Vite
- SCSS
- Open-Meteo API (погода + геокодинг)
- VueUse (`onClickOutside`)

## Возможности

- Поиск города через Geocoding API
- Текущая погода: температура, температура по ощущениям, влажность, ветер, осадки, иконка по `weather_code`
- Прогноз на 7 дней (макс/мин температура)
- Почасовой прогноз с выбором дня недели
- Переключение Metric / Imperial без повторного запроса к API (клиентский пересчёт)
- Адаптивная вёрстка
